# Roadmap

## Delivered for the prototype

- Time clock (active, idle, lost to tools), team ranking on the company server, offline outage logs.
- Live host telemetry, deterministic readiness, and optional structured Ollama explanations.
- Scoped user approval with before-and-after verification of an application-owned CPU workload.
- Independent local/Internet/cloud status, read-only network investigation and a controlled cloud adapter outage.
- On-device history, privacy controls, and replaceable provider boundaries.

## Priorities for a pilot

1. Validate one predefined NQL query and one governed Remote Action against an authorized test tenant. Confirm device identity and data freshness before presenting results.
2. Validate a supported Spark entry point and access policy with tenant administrators.
3. Add optional calendar-file import and narrowly scoped platform-specific microphone and speaker checks with user consent.
4. Harden distribution, OS-level isolation, and local secrets and audit storage for managed endpoints.
5. If the organization needs event synchronization, connect a reviewed destination with explicit policy, field-level filtering, and tested retention and deduplication.
